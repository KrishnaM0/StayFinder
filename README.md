# StayFinder: Making Tourist Renting Easy

**StayFinder** is a user-friendly web application designed to simplify the process of finding and renting hotels or luxury villas. Built with a modern stack using **HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, EJS, REST APIs, and Bootstrap**, it provides seamless functionality for both users and property owners.

---

## Key Features

### 1. User Authentication and Authorization
- **Secure Login/Logout**:
  - Users can log in to manage their villa listings, leave reviews, and interact with the platform.
- **Role-based Access**:
  - Authorization ensures users can only edit or delete their own listings.

### 2. Manage Villa Listings
- Users can:
  - Add new villa or hotel listings with details like **photos, price per night, description, location, contact details, and country**.
  - Edit or delete their listings at any time.
- Each new listing generates a **card view** visible to other users.

### 3. Detailed Property Pages
- Each villa or hotel listing includes:
  - **Photos**
  - **Name and description**
  - **Price per night**
  - **Location and country**
  - **Review stars and user comments**
  - **Contact details for booking**

### 4. User Reviews
- Registered users can leave reviews for any listed property, helping others make informed decisions.

### 5. Responsive Design
- Fully optimized for use across desktops, tablets, and smartphones for a seamless user experience.

### 6. MVC Framework Implementation
- Built using the **Model-View-Controller (MVC)** design pattern for better scalability and maintainability.

---

## Development Goals

StayFinder aims to simplify the process of renting properties for tourists while providing a feature-rich, intuitive, and secure platform. It ensures ease of use for both property owners and users looking for short-term rentals.

---

### Tech Stack
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Templating Engine**: EJS
- **APIs**: REST APIs
